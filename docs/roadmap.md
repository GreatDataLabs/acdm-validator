# Roadmap

Tier 0 and Tier 1 ship in 0.1.0: YAML contracts, typed properties, graph checks, R1-R10, permission
ceilings, maturity, console/JSON output, audits, examples, and CI.

Tier 2 candidates are dbt `meta:` and catalog-tag adapters, a JSON loader, registry APIs, policy-file
configuration, native OpenLineage event integration, OpenTelemetry instrumentation, and reusable
GitHub/Azure tasks. Adapters will feed the same `EntityContract` model so rule behavior stays stable.
