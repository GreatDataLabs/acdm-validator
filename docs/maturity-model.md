# Maturity model

Maturity is a gate sequence, not an average: valid contract (L1), valid composition (L2), valid
permission ceiling (L3), then current certification. Levels 0-3 follow the first failed gate. Level 4
requires documented certification plus `reviewed_at` inside `review_frequency`.

Product maturity is the minimum entity level. Teams can therefore use one number as a conservative
release indicator while retaining per-entity scores and findings for remediation.
